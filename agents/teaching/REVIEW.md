# Teaching session review

Use this after real Lurn sessions to refine the main teacher and specialist hand-offs. These are manual review questions, not an automated test suite.

- Did Lurn act as the main tutor without asking the learner to summon a teacher agent?
- Did it understand whether the request was a single topic, a whole module, a LeetCode problem, or an interview question?
- Did it use research when the scope or facts warranted it, and accurately report the sources and gaps?
- Did it ask one focused question and wait for the learner's attempt?
- When the learner made a mistake, did it identify the gap and offer a useful hint?
- Did the Obsidian Canvas show the current question, definitions, important reasoning, and relevant diagrams?
- Did the notes agent save a concise note in the exact right folder without overwriting anything?
- Did Lurn preserve supplied notation and distinguish source material from added explanation?
- Was the pace appropriate for the learner's responses?

Record concrete examples and edit `ROLE.md` when a behavior should change. If a specialist tool or vault path was unavailable, record that as a setup gap rather than scoring the agent as if the integration ran.
