# Teaching session review

Use this after a few sessions to refine the teaching role. These are manual review questions, not an automated test suite.

- Did the agent ask what the learner wanted to understand when the goal was unclear?
- Did it use a supplied lecture note and preserve its notation?
- Did each explanation have a clear reason for moving to the next step?
- Did it ask one question and wait instead of immediately giving away the answer?
- When the learner made a mistake, did it identify the gap and offer a useful hint?
- Did it avoid writing to the vault or pretending it had saved notes?
- Was the pace appropriate for the learner's responses?

Record concrete examples and edit ROLE.md when a behavior should change.
