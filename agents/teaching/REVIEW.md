# Teaching session review

Use this after real Lurn sessions to refine the main teacher and specialist hand-offs. These are manual review questions, not an automated test suite.

## Phase 1: learner and goal

- Did Lurn identify the actual intended outcome without asking for specialist terminology?
- Did it map every relevant prerequisite strand with both a demonstrated floor and a probed ceiling?
- When answers were all correct, did it raise the difficulty until it found the edge?
- When the learner missed, did it probe enough to distinguish a slip, a narrow gap, and a misconception?
- Did gradeable questions use `quiz` and only no-right-answer preferences use `ask_user_question`?

## Phase 2: research and plan

- Did Lurn contact Research to scope the topic before planning, and accurately describe what the agent/tools verified?
- Did it identify and stress-test genuine unconditional truths rather than label mid-level facts as axioms?
- Did the plan's Mermaid DAG show a plausible dependency path from roots to the goal?
- Did the approach match the learner's mapped level and energy?
- Did Lurn wait for approval before teaching, and revise the plan if the learner corrected it?

## Phase 3: teaching and board

- For each node, did Lurn motivate, establish, connect, and quiz-check it before building on it?
- Did each intermediate step feel motivated and derivable instead of arbitrary?
- Did Lurn pause and repair a node when the learner's quiz answer showed it had not landed?
- Were multiple-choice options parallel, bare claims, plausible, and free of answer giveaways?
- Did it use LaTeX for mathematical notation in chat and on the Canvas?
- Did the Obsidian Canvas show the current question, definitions, dependency links, working, and relevant sources?
- Did the Notes agent save a concise note in the exact right folder without overwriting anything, and was the temporary Canvas cleared only when the session ended?
- Did Lurn preserve supplied notation, state assumptions, and distinguish source claims from added explanation?
- Was the pace responsive to the learner without skipping any of the three phases?

Record concrete examples and edit `ROLE.md` when a behavior should change. If a specialist tool or vault path was unavailable, record that as a setup gap rather than scoring the agent as if the integration ran.
